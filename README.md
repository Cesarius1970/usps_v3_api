# usps_v3_api

Cliente asíncrono e idiomático para la API REST v3 de USPS (United States Postal Service) implementado en Rust.

## Características

- Implementado siguiendo las directrices oficiales de desarrollo de Rust y patrones asíncronos con Tokio.
- Gestión segura de tipos y contratos de la API v3 de USPS.
- Licenciamiento dual estándar (MIT / Apache 2.0).
